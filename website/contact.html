help_outline常见问题

question_answerQ：英语天地应用是免费的吗？

A：是的，英语天地是完全免费的开源应用，所有功能均可免费使用，没有任何隐藏收费项目。

question_answerQ：应用会收集我的个人信息吗？

A：不会。本应用是纯本地运行的学习工具，不收集任何可识别的个人信息，您的学习数据仅保存在您的设备上。

question_answerQ：如何恢复我的学习数据？

A：由于数据保存在本地，卸载应用或清除数据会导致数据丢失，建议您定期备份重要的学习数据。

question_answerQ：iOS 版本什么时候发布？

A：目前我们专注于 Android 平台的优化，iOS 版本正在规划中，敬请期待。您可以关注官网获取最新动态。

question_answerQ：可以提交新的单词或纠错吗？

A：非常欢迎！您可以通过 GitHub Issues 提交单词建议或错误反馈，我们会认真审核并及时更新词库。

question_answerQ：如何参与开源贡献？

A：欢迎前往 GitHub 项目主页 fork 本项目，提交 Pull Request，我们会及时审核。无论是代码、文档还是翻译，所有贡献都非常欢迎！
